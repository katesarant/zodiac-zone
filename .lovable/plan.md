# Αυτόματη ημερήσια ενημέρωση ζωδίων

Σήμερα **δεν** ενημερώνονται αυτόματα. Το αρχείο προβλέψεων έχει μόνο `2026-08-31` (ημερήσιο/μηνιαίο) και παράγεται από script που τρέχει χειροκίνητα, ενώ τα κείμενα ενσωματώνονται στο build — άρα κάθε νέα μέρα θα απαιτούσε και νέο publish. Γι' αυτό βλέπεις παλιές προβλέψεις.

## Τι θα φτιάξουμε

Οι προβλέψεις παύουν να είναι αρχεία μέσα στο build και περνούν στη βάση, με χρονοπρογραμματισμένη παραγωγή κάθε βράδυ. Καμία ανάγκη publish για να ανανεωθούν.

```text
00:05 Αθήνα  ->  cron  ->  /api/public/generate-horoscopes
                              |
                              v
                    AI (1 κλήση ανά γλώσσα, 12 ζώδια μαζί)
                              |
                              v
                        πίνακας horoscopes  ->  σελίδες /el/zodia, /en/zodiac
```

- **Ημερήσιες:** κάθε μέρα στις 00:05 ώρα Αθήνας.
- **Μηνιαίες:** την 1η κάθε μήνα. **Ετήσιες:** 1η Ιανουαρίου.
- **Ασφάλεια δικτύου:** αν μια κλήση αποτύχει, κρατιέται η προηγούμενη πρόβλεψη αντί για κενή σελίδα, και γίνεται επανάληψη.
- **Κόστος:** ομαδοποίηση των 12 ζωδίων σε μία κλήση ανά γλώσσα ρίχνει το ημερήσιο κόστος από ~24 κλήσεις σε 2 (περίπου 0,15–0,35 credits/ημέρα αντί 0,9–1,8).
- Τα υπάρχοντα αρχεία JSON μεταφέρονται στη βάση ώστε να μη χαθεί το ιστορικό/archive και το sitemap.

## Τεχνικά

1. Migration: πίνακας `public.horoscopes` (period, key, lang, generated_at, signs jsonb, unique(period,key,lang)) με GRANT σε `anon` (μόνο SELECT) + `service_role`, RLS με public read policy. Seed με τα υπάρχοντα αρχεία ως INSERT.
2. `src/lib/horoscope/files.server.ts`: ανάγνωση από τη βάση (publishable client) αντί για bundled glob· fallback στα bundled JSON αν η βάση είναι άδεια.
3. Νέο route `src/routes/api/public/generate-horoscopes.ts`: έλεγχος secret header, υπολογισμός ημερομηνίας Αθήνας, παραγωγή μόνο όσων λείπουν, upsert στη βάση, retry + fallback στην προηγούμενη περίοδο.
4. Batched prompt στο `generate.server.ts`: ένα request που επιστρέφει και τα 12 ζώδια, με τον ίδιο έλεγχο απαγορευμένων όρων ανά ζώδιο.
5. Χρονοπρογραμματισμός με pg_cron/pg_net προς το σταθερό production URL, με το secret σε header.
6. Το sitemap και οι σελίδες archive διαβάζουν πλέον τα κλειδιά από τη βάση.
